# 3、TCP、UDP

## 网际层（网络层）协议 - IP

- IP 所提供的服务是无连接、不可靠的
- 在网络性能良好的情况下，IP 传送的数据能够完好无损的到达目的地
- 所谓的无连接是指不管接收方是否已做好接收数据的准备之前就发送数据
- 至于不可靠的连接，是指目的系统不对成功接收的分组进行确认
- 因为无连接、不可靠，所以要将差错检测、流量控制、拥塞控制服务授权给其他各层协议

## TCP（传输层）

- 面向连接，可靠的
- 在 IP 提供的不可靠数据服务上为应用程序提供了一个可靠的、面向连接的全双工数据服务
- 三次握手
- 连接管理、差错校验和重传、流量控制、拥塞控制、端口寻址
- 流量控制采用的是：可变大小的滑动窗口协议
- TCP/IP 和 ISO/OSI 中建立连接是在传输层，OSI/RM 中建立连接在会话层

## UDP（传输层）

- 无连接的、不可靠的
- 错误检测功能弱于 TCP
- 有助于提高传输速率
- 拥有端口寻址功能
