# 10、网络相关命令

## windows

- ipconfig/release：DHCP 客户端手动释放 IP 地址
- ipconfig/flushdns：清除本地 DNS 缓存
- ipconfig/displaydns：显示本地 dns 内容
- ipconfig/registerdns：DNS 客户端手工向服务器进行注册
- ipconfig：显示所有网络适配器的 IP 地址、子网掩码和缺省网关值
- ipconfig/all：显示所有网络适配器的 TCP/IP 配置信息，包括 DHCP 服务是否启动
- ipconfig/renew ：DHCP 客户端手动向服务器刷新请求（重新申请 IP 地址）
