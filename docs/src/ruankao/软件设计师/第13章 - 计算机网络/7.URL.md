# 7、URL 和浏览器

## URL 格式

协议名：//主机名.域名.域名后缀.域名分类/目录/网页文件

## 域名后缀含义

| 组织模式 | 含义             |
| -------- | ---------------- |
| com      | 商业组织         |
| edu      | 教育机构         |
| gov      | 政府机构         |
| mil      | 军事部门         |
| net      | 主要网络支持中心 |
| org      | 上述以外组织     |
| int      | 国际组织         |

| 地理模式 | 含义     |
| -------- | -------- |
| cn       | 中国     |
| hk       | 中国香港 |
| mo       | 中国澳门 |
| tw       | 中国台湾 |
| us       | 美国     |
| uk       | 英国     |
| jp       | 日本     |

## 浏览器

- 输入网址后，本地主机将首先在本地 host 中查询，再到本地 DNS 缓存，再到本地 DNS 服务器，再到根域名服务器
