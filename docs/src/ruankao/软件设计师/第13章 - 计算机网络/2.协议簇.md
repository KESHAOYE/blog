# 2、协议簇

## 七层模型（OSI）

- 应用层
- 表示层
- 会话层
- 传输层
- 网络层
- 数据链路层
- 物理层

## 五层模型（TCP/IP）

- 应用层
- 传输层
- 网际层
- 网络接口层
- 硬件层

## ICMP（网络/网际层）

- 是 internet 控制信息协议
- 利用 IP 传送报文

## FTP 文件传输协议（应用层/表示层/会话层）

- 21 是控制端口
- 20 是数据端口

## Telnet 远程登录协议（应用层/表示层/会话层）

- 23 端口号

## SMTP（simple mail transfer protocol） 电子邮件协议（应用层/表示层/会话层）

## NFS 网络文件服务协议（应用层/表示层/会话层）

## SNMP 网络管理协议（应用层/表示层/会话层）

- 采用 UDP 进行传送

## TCP

- POP3
- FTP
- HTTP
- Telnet
- SMTP

## UDP

- DHCP
- TFTP
- SNMP
- DNS
