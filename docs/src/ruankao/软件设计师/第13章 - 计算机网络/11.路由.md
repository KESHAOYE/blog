# 11、路由

windows 服务器收到一个 IP 数据包时，先查找主机路由，再查找网络路由（直连和远程），这些路由失败以后再查找默认路由

## 类型

| 路由类型    | 说明                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| 直连网络 ID | 用于直接连接的网络，Interface 可以为空                                                                  |
| 远程网络 ID | 用于不直接连接的网络，可以通过其他路由器到达这种网络 Interface 字段是本地路由器的 IP 地址               |
| 主机路由    | 到达特定主机的路由，子网掩码是 255.255.255.255                                                          |
| 默认路由    | 无法找到确定路由时使用的路由，目标网络和网络掩码都是 0.0.0.0                                            |
| 持久路由    | 利用 route add -p 命令添加的表项，每次初始化时，利用这种路由都会加入 Windows 的注册表中，同时加入路由表 |

**对于某个目标有多条路由，采用距离小的路由来源提供的路由信息**
