# 1、设计模式概述

## 要素

- 每一个模式描述了一个在我们周围不断重复发生的问题，以及该问题的解决方案的核心
- 采用设计模式**以复用成功的设计**

## 分类

按照设计模式的目的可以分为三大类：创建型（与对象的创建有关）、结构型（处理类或对象的组合）、行为型（对类或对象怎样交互和怎样分配职责进行描述）
每种模式也分为类模式和对象模式

|      | 创建型                                                                                                         | 结构型                                                                                                                                                                          | 行为型                                                                                                                                                                                                                                            |
| ---- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 类   | 工厂方法模式（Factory Method）                                                                                 | 适配器模式（Adapter）（类）                                                                                                                                                     | 解释器模式（Interpreter）<br/>模板方法模式 （Template Method）                                                                                                                                                                                    |
| 对象 | 抽象工厂模式（Abstract Factory）<br/>生成器模式（Builder）<br/>原型模式（Prototype）<br/>单例模式（Singleton） | 适配器模式（Adapter）（对象）<br/>桥接模式（Bridge）<br/>组合模式（Composite）<br/>装饰模式（Decorator）<br/>外观模式（Facade）<br/>享元模式（Flyweight）<br/>代理模式（Proxy） | 责任链模式（Chain of Responsibility）<br/>命令模式（Command）<br/>迭代器模式（Iterator）<br/>终结者模式（Mediator）<br/>备忘录模式（Memento）<br/>观察者模式（Observer）<br/>状态模式（State）<br/>策略模式（Strategy）<br/>访问者模式（Visitor） |
